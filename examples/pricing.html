FAQ / NATIVE DISCLOSURE

No runtime required.

A pricing layout adapts to the available space, including when embedded in a narrow app panel.

Does this library require Tailwind?

No. Syntyr distributes ordinary CSS and can coexist with a Tailwind app, but does not require Tailwind tooling.

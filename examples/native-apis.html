System status: operational. This content is accessible without HTML Invoker Commands.

Content-sized inputs

On browsers supporting field-sizing: content the field grows with text (up to 24rem). Other browsers keep a normal resizable textarea.

Progressive motion

The thin top-of-page indicator uses a native scroll timeline in supporting browsers. It is decorative and hidden when reduced motion is preferred. The popover entrance effect is opt-in and follows the same preference.

Scroll this page to inspect the progress indicator. There are no scroll listeners, animation observers or client dependencies. The position and size of the content remain stable while the indicator updates.

For content-rich pages, consider server-rendered sections with links and headings first. Use IntersectionObserver only when the application genuinely needs to defer work or track visibility.

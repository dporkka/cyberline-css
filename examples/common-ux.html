Common website and application UI

Browser-native interactions work without JavaScript. Clipboard feedback is explicitly optional and the disabled copy button stays disabled without enhancement.

Dropdown actions (native popover)

Use links for navigation, not a fake ARIA menu. Native light-dismiss and keyboard focus remain browser-owned.

Detail drawer (native dialog)

Image gallery and lightbox

Click a preview to open its image in a native modal; the fallback image is still visible without script.

Native date-range form

Two native date fields preserve platform pickers and server rendering. Always validate the date order on the server, including timezone and inclusive/exclusive endpoint policy.

Clipboard and toast feedback (opt in)

The Clipboard API requires a secure context and user activation. This example reports failure rather than pretending a copy succeeded.

Syntyr CSS: semantic HTML, native APIs, optional enhancements.

All dropdown, drawer and gallery navigation is native. Browser support for invoker commands varies; provide ordinary links when older browsers are a requirement.

All presentation effects use CSS custom properties and semantic HTML.

Works without JavaScript or a component framework

Load syntyr.core.css, apply data-syn-theme and data-syn-density, then compose standard semantic HTML. For stronger sci-fi shapes, optionally load syntyr.geometry.css. For accessibility, verify color contrast and target sizes in your own application and avoid relying on visual appearance alone to express state.

EVALUATE BEFORE YOU BUY / FREE EXAMPLES

Test Syntyr on your real stack

Open the existing MIT examples, inspect their HTML and CSS, then try a real integration before evaluating a future paid screen kit. The private Console Kit screens are not available for download or purchase.

  1. Inspect a complete operations console with fictional data, responsive panels and native HTML controls.
  2. Use the component playground to check mobile/tablet widths, density and disabled/invalid states; copy the markup into your application.
  3. Try semantic theme overrides and check text/background as well as primary-button contrast.
  4. Check your backend's real form behavior, keyboard focus, accessibility, and integration effort. Static examples do not implement authentication, persistence or billing.

No delivery date, support plan or final license is offered yet. All essential components and all free CSS themes remain MIT and free. The future premium license would apply only to new, separately authored page compositions.

Current status and buyer boundaries

Included in the private prototype

Not implemented
